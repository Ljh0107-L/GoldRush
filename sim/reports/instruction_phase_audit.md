# `f18064c` 动态指令锚与相位归因修正

日期：2026-08-10。零平台配额；全部插桩、消融和 harness 位于 `/tmp`，`src/player.cpp` 保持
`f18064c` 字节状态。

## 1. 659 指令锚为何失效

旧 `INFRA` 使用 `(perf_total - 2566352) / 4481` 得到约659条，但当前 `tests/bench.cpp` 实际调用数
是 `7×500=3500`，4481没有可复现来源。

独立 harness 通过 `perf_event_open(PERF_COUNT_HW_INSTRUCTIONS)` 只包住确定性调用循环，重复1000遍
500轮，即500,000 calls：

| 对象 | 三次结果（instr/call，含同一 harness） |
|---|---|
| `f18064c` | 903.230244 / 903.230246 / 903.230242 |
| trivial | 15.014088（trivial函数objdump为6条） |

同一循环 harness 约9.014条，因此现役函数本体为 **894.216±0.000002条/call**。旧659低估36%。
平台190ns在10条输入载荷口径下要求指令经验价：

```text
(190 - 40 - 20) / 894.216 = 0.14538 ns/instruction
```

旧0.2高估38%；`659×0.2` 的巧合命中来自两个反向误差抵消，而非正确标定。

## 3. scan 390条在做什么

静态标签将每单位scan拆为约160条比较/选行和约42条炸弹持久化：

- 每单位固定5条`vmovdqu`，同一载入同时供金币和炸弹；没有重复载入金币/炸弹；
- 每单位10条向量比较（5个gold `>2`、5个bomb `==-3`）；
- `kmovd`把8-lane比较mask转入标量；
- `shl/shrx/and`按窗口列偏移将8bit压成局部5bit，并应用越界有效掩码；
- 每行查询`TT.bestrow`，保存环距优先候选；
- 炸弹5行先拼成25bit，再拆行、按全局列移位，OR进跨轮`bombbit`；
- `lea/movsx/cmovbe/cmp`负责行钳位、边界有效性与表地址。

所以它**不是逐格标量提取金额**：金额阈值比较已留在向量域；标量链服务于下游5bit/25bit位图、
行LUT和跨轮炸弹状态。可优化点是减少mask打包再拆包、边界/位移链和行候选归约，而不是再“向量化
一次载入”。

### 3.1 几何重叠不是操作冗余

六局/图、3000轮的两窗口格重叠：

| 图 | mean / median格 | 非零 | ≥9格 | 完整histogram `overlap:count` |
|---|---:|---:|---:|---|
| map1 | 4.92 / 3 | 57.5% | 24.0% | `0:1275,1:33,2:108,3:165,4:206,5:160,6:133,8:200,9:73,10:119,12:182,15:136,16:73,20:137` |
| map2 | 5.25 / 4 | 59.7% | 24.6% | `0:1209,1:33,2:74,3:124,4:268,5:161,6:162,8:232,9:85,10:99,12:152,15:145,16:97,20:159` |
| map3 | 7.92 / 8 | 74.0% | 42.9% | `0:780,1:10,2:23,3:41,4:181,5:365,6:61,8:251,9:78,10:224,12:263,15:242,16:170,20:311` |

但实际操作单元是`(clamped row, AVX cb)`。两单位完全相同的AVX行载平均只有0.312/0.298/0.528条，
非零仅13.6%/12.7%/26.1%。即使整条39.4指令行管线免费共享，上限也只有12.3/11.7/20.8条，
约20/19/33金，尚未扣匹配、重排和重新生成两个局部mask的成本。

“扫描并集一次”理论上可保持pair_diff，前提是精确重建两个局部mask与优先序；但在当前行载粒度
没有正头寸。**冗余必须按实际操作粒度测量，不能用语义格重叠推导行载冗余。**

### 3.2 可达下限

保留三图pair_diff 0/500的现实目标是390→290-330条，节省60-100条：

- 行内直接持久化炸弹，减少25bit pack→unpack；
- 将边界/列位移表进一步预折叠；
- 五行候选保持寄存器内归约，减少标量搬运。

理论上只数10载入+20比较会得到30条，但它遗漏位图语义、边界和状态写，不是可施工下限。

## 4. route约271条拆解

RDPMC给出`blk`39.4 + route231.5。静态块为blk 16条/单位、route 55条/单位，余量来自条件helper
与动态路径：

1. `blk[19]`向量合成墙与富度门炸弹：约39条；
2. 目标位移钳位、SL表地址与三步累计坐标：正常路径骨架；
3. 三个动态位置的墙/弹位测试；
4. 站金四邻查询+ctz折返；
5. 受阻时`steerStep/escapeStep`的pass01、回头mask和ctz。

500k-call边际指令消融：只保留首步检查省61.14条；完全不检查省126.67条；blocked直接STAY省
110.21条。它们改变后续路径且彼此重叠，不能相加。四核心同时消融只省205.59条≈29.9ns，证明
旧“50ns器官和”是重叠边际与10ns量化共同造成的错觉。

安全检查、自愈均为高价值行为，不可删除。现实route golf只能瞄准重复地址计算、mask查询与表指针
停放，估计省20-40条；`blk`直接读取方案历史上因高频内联加载反而+230条，不能复活。
