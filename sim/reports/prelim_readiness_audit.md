# 初赛就绪度审计：指纹误锁修复 + 排名机制重定向

> 2026-08-10。审计三项：排名机制、全场位置、陌生图鲁棒性。
> 结论：**修了一个静默腰斩的交付级 bug；同时发现我们两晚在优化一个几乎不影响排名的目标。**

## 0. 三项结论

| 项 | 结论 |
|---|---|
| 1. 排名机制 | **循环赛 × 胜率排名，已从主文档确证**；但「每对打几局 / 用哪个提交位 / 初赛期能否改代码」三项**未确证**，其中"提交位"一项若猜错会归零整周工作 |
| 2. 全场位置 | **不在前 16**：我方 rank 92、胜率 23.68%，前 16 门槛 68.69%，差约 **45 个百分点**。T-1 是唯一断层第一(96.48%)，**Tundra 连前五都不是** |
| 3. 陌生图鲁棒性 | **无硬故障**（10 图 × 500 轮零异常零非法）；但发现**指纹误锁**：三张已知图全部可被"同边框换内部"的图欺骗，代价 −470~−806 金/局且**永不自愈**。已修复并落库 |

## 1. 陌生图审计：发现并修复指纹误锁

### 1.1 好消息先说
在赛事机用真 AVX 构型跑 7 张新造图 + 3 张已知图（各 3-4 seed、被动对手、500 轮）：
- **零硬故障**：10/10 图跑满 500 轮，无异常、无非法输出、无判负。
- **陌生图 fallback 真的工作**：6/7 新图正确判为 unknown → 转 LAZY，收入 1409-1986，与已知图（1681-1760）同档。
- **`fixAnchor` 有效**：把 `(6,8)/(11,8)` 两锚点直接砌成墙并围一圈（`anchorwall` 图），仍拿 1572、all-stay 0 轮。
- 最难的 `dense`(81 墙) / `corridor`(79 墙) 未崩，blocked 升至 36-42%，收入 1409/1648。

### 1.2 病灶：指纹误锁，三图全中
指纹淘汰**只比对已观测格**（`seen` 掩码）。两单位从 (0,0)/(16,16) 出发，round 0 只看到两个角落。
我造了三张对抗图 `mimic1/2/3`：**外圈与对应已知图逐格相同，只改内部 5-11 行/列**。结果全部误锁：

| 图 | 冻结构型 | 修复后 | 差 | 冻结构型判定 |
|---|---:|---:|---:|---|
| `mimic1` | 909 | **1511** | **+602** | locked map1（错） |
| `mimic2` | 1017 | **1529** | **+512** | locked map2（错） |
| `mimic3` | 762 | **1568** | **+806** | locked map3（错） |

**代价从"地形更难"里被干净分离出来**：`mimic1_broken` 与 `mimic1` 是同一张地形、只把 (2,1) 一格墙改成空地使 map1 候选被淘汰 → 885 vs 1574。**同地形差一格，误锁本身值 −689 金。**

误锁为何致命且不可恢复（`src/player.cpp`）：
1. 锁定后 `bpw` 被 `0xFFFC0001u | BAKED_W[m][r]` 直灌 —— **既相信不存在的墙（挡住合法走位），又不知道真墙（往墙里走→被挡）**。
2. **锁定后学习循环被整体跳过**（原 `if (g_s.map_id < 0)` 才学），且原门控是 `mode != 0` 外套站格门控，**一旦转 FAST，`slowTick` 再也不被调用** → 整局 500 轮再不复核一次。

**这是最难发现的一类失败：不崩、不判负、日志上完全正常，只是收入腰斩。**

### 1.3 修复：锁定后限窗复核，矛盾则不可逆退回懒学习
- 学习循环不再被 `map_id < 0` 门控；已锁时**只比对不改表**，发现确定性矛盾 → `map_id = -2`、清幻影墙（`bpw` 只留边界哨兵）、清 `seen`/`visited` 重新观测、`fixAnchor` 重定锚。
- **grid 语义严格区分**：`-5` 雾跳过，仅 `v == -1` 视为墙；炸弹 `-3`、金币 `≥1`、空地 `0` 一律非墙。若把弹或金误读成墙，已知图上会每局误退，比原病更糟。
- 热路径门控改为扁平式：`mode==1` 恒进；`mode==2` 照旧长驻；**FAST 只在 `round <= VERIFY_ROUNDS(24)` 内**按站格门控进入。

**为什么限窗**：实测误锁矛盾在 **round 3-4** 就被观测到（mimic1/2/3 × 5 seed **全部一致**），而不限窗会让已知图整局跑 ~90 次窗口扫描、白付 **+21~24 cycles ≈ −77 金**。限窗后降到 **+6~9 cycles ≈ −31 金**，仍留 6 倍余量。
漏报面是"仅在极少踏足的外围区域与烘焙表矛盾"的图 —— 而**错墙只在我们实际经过的区域才挡路**，那种矛盾本身几乎不产生损失，故这是与代价结构匹配的取舍。

### 1.4 五道门实测

| 门 | 要求 | 实测 |
|---|---|---|
| 1 | 三图 `pair_diff` 0/500 | **0/500/0/500/0/500** ✅ |
| 2 | 复核确实执行且零误触发 | map1/2/3 分别比对 **2285 / 2113 / 1240 个格**、**0 次误触发** ✅ —— 零不是因为代码没跑 |
| 3 | mod64 == 0x10 | 首次构建落 `0x20`，按护栏建议把 `.space` 48→**96** 后回到 **0x10 @ 0x1a50** ✅ |
| 4 正面 | `mimic*` 恢复 | +602 / +512 / +806（均值 **+640**）✅ |
| 4 反面 | 已知图与 6 张正确判定图不退化 | **同 seed 逐图 delta = +0 exactly（9/9）** ✅ |
| 4 附加 | map2/map3 是否也有漏洞 | **是，三图全中**，攻击面是我最初判断的 3 倍 ✅ |
| 5 | 四元组重登记 | 新 SHA `f6647163…`，见 CHANGELOG ✅ |

**平台验收（8 局 map1 自博弈，成对换座）**：ΔP50 `−7.50±6.20 ns (1.21σ)`、ΔP90 `+2.50±13.19 ns (0.19σ)` → **无布局税回归，96B 死垫有效**。槽位效应再次显形（fix@p1 得 −17.5/−20.0，fix@p2 得 +2.5/+25.0），换座后抵消 —— 军规 32 第二次得到验证。

### 1.5 成本收益
- **成本**：已知图 **−31 金/局**（限窗后），且**行为逐位不变**（`pair_diff` 0/500，同 seed 收入 delta = 0）。
- **收益**：误锁图 **+640 金/局**。
- **打平概率** ≈ 31/(640+31) ≈ **4.6%**。赛事方明确不保证沿用当前地图，而"保同一套边框、换内部布局"是最自然的出图方式，**远超 4.6%**。

## 2. 排名机制（主文档确证部分）

- **胜率排名 + 全循环赛**：`docs/赛制介绍.md:35`「所有参赛队伍进行循环赛，每支队伍与其他所有队伍进行 1v1 金币争夺赛，**按胜率排名**」；引擎自动汇总对战（`:33`）。
- **前 16 晋级**（`:39`），**无任何按图分项**。
- **延迟不直接进排名**：只有两条间接通道 —— 每轮先手权、以及净分相同时 P90 决胜；另有独立的延迟专项奖。
- **判负**：非法输出 / 运行时错误 / 300ms-60s 池耗尽 → **该局直接判负，无逐轮容错**。

**未确证三项（按军规 27 不猜）**：① 每对打几局、用几张图 —— 赛事方明确「暂时无法透漏」；② **初赛引擎用哪个提交位**（`add_model_1` 逐局 vs `add_model_4` 公开防守位）；③ 初赛期间能否继续改代码（`FAQ.md` 第三节整节为空）。

## 3. 全场位置：目标函数一直是错的

| | |
|---|---|
| 全场规模 | ≥117 队（榜单硬上限 100 行 + 17 支有公开模型但未上榜） |
| 我方 | rank **92**、胜率 **23.68%**、P90 300ns（**全场第二低**） |
| 前 16 门槛 | rank16 Ausdroid **68.69%** → 差 **约 45 个百分点** |
| T-1 | rank 1、**96.48%**，唯一断层 |
| **Tundra** | **不在前五**（#2-5 是 ZZK 85.03 / rocket dogs 83.15 / 量衡量化 82.57 / rikka 82.09） |

**关键算术**：全循环赛 + 胜率排名下，T-1 与 Tundra 合计只占分母 **2/117 ≈ 1.7%**。把这两队从 36% 打到 100%，**最多值 +1.7 个百分点**，而缺口是 45 个百分点。**我们两晚把全部工程量投在了一个上限 1.7pp 的目标上。**

而且**中游已经在赢我们**：对 Ausdroid（rank 16，正好卡在晋级线上）我方 **1胜14负**，其中含四个 230-260ns 的冠军级构型；对手 P90 758ns-259μs，**我方稳吃先手权仍然输** —— 独立印证了 `AGENT.md:57`「先手权不自动变现」。

### 3.1 但 23.68% 不是现役构型的能力（重要修正）
- 归档里我方一侧有数百个实验构型名；**10 局判负全部是我方**，但**全部来自实验线**（`L3mid/L4tun/L4t1/L4mid/L8p/Lsp/Ltp/Lxp/Lzv1` 6 次 SIGSEGV + 3 次 `action_out_of_range`，以及 `champ76e` 那次已知的 Intel 误编 SIGILL）。**冻结构型 36 局零判负。**
- **`AGENT.md:120` 早已写明「天梯防守位换代（现挂 `cpp27b` 已三世代落后）」—— 这条待办从未被执行。** 若榜上「外战胜率」统计的是他人挑战我方**公开防守位**的结果，那 23.68% 衡量的是一个三代前的旧构型，不是现役构型。

## 4. 建议的优先级重排

| 优先级 | 动作 | 依据 |
|---|---|---|
| **P0** | **确认初赛用哪个提交位；若是公开位，立刻把防守位换成现役构型** | 单次 `publish` 调用即可；若猜错则整周工作归零。`AGENT.md:120` 已挂待办 |
| **P0** | **提交纪律：任何上平台的构型必须先过 `tests/verify_construct.sh` + 陌生图合法性审计** | 10/10 判负是我方实验构型；判负一局的排名代价与赢一局对称 |
| **P1** | **通用采集质量**（命中率线在跑） | 缺口 45pp 只能靠通用能力，且中游对手已在赢我们 |
| **P1** | **map1 专项** | 唯一两条战场全负的图，且全部中游证据都在 map1 |
| **P2** | 顶部两队专项（当前工作） | 天花板 **+1.7pp** |
| **P2** | 继续压延迟 | 排名回报 ≈ 0（不直接进排名，且我方 P90 已全场第二低） |

**注意本审计不建议"改成不输中游"** —— 那是结果不是杠杆。真正的杠杆是通用采集质量；它一旦上去，中游、t1f2（−72 金）、frTu1 都会一起翻。

## 5. 未决与风险
- **提交位问题无法从仓库回答**（`FAQ.md` 初赛节为空），需向赛事方确认或用 8.15-16 模拟赛实测。**这是本审计唯一"猜错会归零整周"的项。**
- 限窗复核的漏报面：仅在外围区域与烘焙表矛盾的图检测不到；已论证该类矛盾损失极小，但未实测。
- 死垫现为 **96 字节**，仍与 `decide` 体积耦合；改 `decide` 必须重跑 `tests/verify_construct.sh`。
