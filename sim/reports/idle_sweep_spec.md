# 中央空转扫掠、选靶钳制与寄生跟随下岗：本地先验

## 结论摘要

1. **B/C 本地仅近中性排序，C 优于 B。** 两点摆动 B 的两腿平均收入差中位 -11.25；四格小环 C 为 -7.75。C 是唯一同时小幅降低零拾取率的移动臂，可作为平台复判候选，但本地不构成上线证据。
2. **D/D' 本地判负，平台也已判负。** 硬钳制 D 中位 -73.5，软钳制 D' 中位 -57.5；随后平台 V5 软钳制为 -207.8 金 / 2.22σ，R1 仅 72.98%→74.94%。停止选靶钳制方向。
3. **“模拟器 R1=97% 已饱和”的归因被推翻。** 97% 属于本实验的简化 Python 锚点策略，不是现役冠军。冻结 `ff462756` 同源策略在真实 10 局 R1=69.46%，模拟器 10 局=63.66%，差 -5.8pp，而不是 +24pp。
4. **寄生跟随下岗是强正先验。** 第一刀 `da210b8` 与仅把 `live` 恒置 0 的 `/tmp` 变体跑 20 对，no-hunt 收入差中位 +151.5、均值 +145.2，17/20 对为正；u1 R1 +6.99pp，u1 零拾取 -7.85pp。

本阶段从未修改 `src/player.cpp`；所有 C++ 变体只存在于 `/tmp` host 编译副本。

## 1. A/B/C/D/D' 配对设计

每个处理臂都与 A 跑 map1/map2 各 15 个 seed，共 30 对、60 局；每个 seed 跑 A-vs-X 和 X-vs-A，固定 P1 先手并换座合并。

- **A**：相同 5x5 三步局部采金器；窗口无金才回 (6,8)/(11,8) 并 STAY。有金时允许连续追逐，不人为加距离 3 的软绳。
- **B**：空窗时在锚点与朝中心邻格之间三步往复。
- **C**：空窗时沿含锚点的 2x2 四格环三步循环。
- **D**：目标金额只计算中央 9x9；中央窗口无金即归锚/STAY。
- **D'**：中央目标优先；仅中央窗口无金时允许追外圈可见金。

完整 seed、scenario digest、双腿分数与行为汇总见 `sim/reports/idle_sweep.json`。

## 3. 钳制放弃了什么

只使用 P1（始终先于 NPC/P2）的 A 腿，可按引擎 65% 拾取规则逐步精确重建拾取来源：

- D 对照 30 局：中央 9x9 外金额占 **8.67%**，拾取格事件占 4.82%，外格每次实际拿 6.19 金。
- D' 对照 30 局：中央外金额占 **8.05%**，拾取格事件占 4.50%，外格每次实际拿 6.16 金。

开题的“外格中位 20”是格上原始存量且条件在已有金；玩家单次实际只拿 `ceil(65%)`，并混有普通外圈格。D/D' 用约 1–2pp R1 改善交换 8% 左右真实收入来源，本地排序 D'<D 合理；平台 D' 的 -207.8 金最终封棺该方向。

## 4. 空间保真度复核：推翻错误的 97% 对比

### 统一口径

- R1：row、col 都在 [4,12]。
- d≤2：到 (8,8) 的切比雪夫距离不超过 2。
- player1 两个自有单位；每单位每轮一个 end endpoint；无可见率过滤。
- 真实语料：`logs/opponents/_selfplay-champ/` 10 局，身份 `champff4`。
- 模拟语料：同源冻结 commit `ff462756`，host ABI 标量 fallback，prefetch-only 调用 no-op；相同 probeobs、10 seed。

### 结果

| 指标 | 真实 10 局 | 同构模拟 10 局 | sim-real |
|---|---:|---:|---:|
| end R1 全轮 | **69.46%** | 63.66% | -5.80pp |
| end d≤2 全轮 | 38.18% | 32.00% | -6.18pp |
| end R1 r<20 | 86.25% | 81.50% | -4.75pp |
| end R1 r≥20 | 68.76% | 62.92% | -5.84pp |
| u0 R1 | 91.68% | 94.90% | +3.22pp |
| **u1 R1** | **47.24%** | **32.42%** | -14.82pp |
| 中央生成份额 | 50.68% | 49.20% | -1.48pp |
| 中央其他 actor 数/快照 | 4.565 | 4.554 | -0.011 |
| 中央 remaining/快照 | **39.16** | **27.03** | -12.13 |
| champion 正拾取单位轮 | 33.43% | 24.56% | -8.87pp |
| 外圈段 P90 | 22 轮 | 29 轮 | +7轮 |

结论：

1. **不是开局平均造成。** 开局 R1 反而高，剔除后真实值从 69.46% 降到 68.76%。
2. **不是统计口径差。** start/end 仅约 0.1pp；unit-round、R1 边界已固定。
3. **不是“中央挤压 actor 数”差。** 快照扣除我方后，其它中心 occupants 均值几乎相同。
4. **不是生成份额主导。** 中央生成份额只差 1.48pp。
5. 残差集中于 u1；模拟中央存量少 31%、正拾取轮少 8.9pp、外圈段更长，符合已知 NPC 过强/偏中央使 u1 远征更难结束。

最重要的修正是：**97% 是简化 Python A，不是同构冠军。** 不同策略的 97% 与平台第一刀约 73% 不能拼成“模拟器 24pp 饱和裂口”。`_selfplay-champ` 这 10 局本身也只复现 69.46%，不是 73%；73% 属于后续第一刀 cohort，需拿到对应日志再复算。完整证据见 `sim/reports/spatial_gap.json`，规则已补进 `sim/README.md`。

- map1，20 seed，每 seed 两腿换座；固定 P1 先手。

## 6. C++ 规格与预算（本报告不实施）

### B/C 空转移动

- 只挂在现有 `goldm==0` 回落路径；不得新增高频真假熵分支。
- B 可用每单位两位置×三动作共 12B LUT；C 可用每单位四 phase×三动作共 24B LUT。
- 位置偏离预期（追金、阻挡）时复用现有归锚，不另建 BFS；到达环格再恢复 LUT。
- B 估算 +4~8 指令/空窗单位轮，C +8~15；`.text` 目标 <150B、rodata <32B、状态最多 1B phase。按 0.2~0.32ns/指令约 +1~5ns，仍需同构 perf/平台确认。
- 排序仅支持 C 作为平台候选，不支持直接实施。

### D/D' 选靶钳制

- 窗口中央掩码可由 17-entry 行/列 5-bit LUT 合成；D 为 `goldm &= mask`，D' 为 `cm=goldm&mask; goldm=cm?cm:goldm`，应编译为 cmov，无分支。
- 估算 +5~10 指令/单位、rodata <64B、零状态；原始预算可压在 230ns 内。
- **但平台 V5 已以 -207.8 金 / 2.22σ 判负，不得复活。**

### 寄生跟随下岗

- 删除/禁用 `visible_enemies -> hunt_r/c/t -> anch_r/c[1]` 的热路径覆盖；保留正式远征 `exc` 的保存/恢复语义。
- 若整块删除，`hunt_r`、`hunt_c`、`hunt_t` 和只为寄生回驻服务的 `bh_r/bh_c` 可一起审计下岗，状态最多净减 6B。
- 这是**负指令刀**：预计删约 20~30 热路径指令、约 100~180B `.text`、无新增分支；按 INFRA 裸系数预计 P50 改善约 6~10ns，而非付税。
- 实施仍由主线 Worker 完成，必须 pair_diff 解释预期行为差、同构 perf、平台 probeobs 收益与 u0/u1 R1/零拾取交叉验证。
