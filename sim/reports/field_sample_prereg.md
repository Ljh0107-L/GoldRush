## 0. 先撤回一条我自己上报过的「交叉验证」

我曾报：实测 `f(0)=0.000511/金` ⇒ `σ_eff = 0.3989/f(0) = 781`，与独立测得的队内单局 SD `766` **相差 1.9%**，称之为两条独立路径的交叉验证。

**撤回。两个理由，第二个是致命的：**

1. **公式前提不成立。** `σ = 0.3989/f(0)` 要求 `f(0)` 是分布的**峰值**密度（中心在 0）。实测 margin 分布重度负偏（52.6% 低于 −400）⇒ `f(0)` 是**肩部**密度。实算：若 `μ=−600, σ=766`，则 `f(0)=0.000383` 而 `0.3989/f(0)=1041`，**把 σ 高估 36%**。
2. **`766` 是我自己两小时前判定为被灌水的那个数**（archive 汇总，333 局跨约 300 个我方构型；低构型数对手实测只有 189–213）。拿它与一个从 pooled 分布导出的量比较，**两者被同一个偏倚污染** ⇒ 不是独立路径。

⇒ 降级为：**「两个受同源偏倚影响的量数值接近，不构成验证」**。判例归入军规「闭合得很漂亮的分解恰是最容易过审的错误形态」。

## 1. 预测 ①：斜率（头号产出）

**恒等式（密度法在此是精确的，不是近似）**：
```
f_pooled(0) = 按局数加权的 mean_i [ φ(μ_i/σ_i) / σ_i ]
```
archive 的 `0.0511 pp/金` 是**对 archive 语料**的正确斜率；而该语料 **263/333 局（79%）打 T-1/Tundra**，那两支同时满足两个压低斜率的条件：

| | T-1 | Tundra | 干净对手 |
|---|---:|---:|---:|
| `μ_i`（离 0 多远） | −783 | −676 | ±7 … ±138 |
| `σ_i` | 786 | 962 | **189–213** |
| ⇒ `φ(μ/σ)/σ` | 极小 | 极小 | **大** |

**关键机制**：那些 `σ_i = 786/962` 由**我方构型 churn** 造成，不是对局固有噪声。`fd47ea6` 是**单一冻结构型** ⇒ 其 `σ_i` 应落在干净档 **≈200**。

> ### 预测（数据到达前）
> **32 局的斜率将显著高于 archive 的 0.0511，落在 `0.10–0.25 pp/金` 区间。**
> 机制两条：(i) 单一构型使 `σ_i` 从约 766 降到约 200；(ii) 分层名单不再由「打两强」主导，`μ_i` 分布靠近 0。
> 若成立，补 17.6pp 只需约 **70–176 金/局**（中点约 88），而非 320。
>
> ### 否证条件
> **若实测斜率落在 `[0.04, 0.07]`（与 archive 一致），则上述两条机制\*都\*不成立。** 那意味着 `σ_i` 的「构型灌水」解释是错的，必须重新解释「为什么单一构型下 σ 仍约 780」。

### ⚠️ 两个效应方向相反，不得只取有利的一半
带宽 ∝ σ ⇒ **σ 收窄会让落在带内的\*队数\*减少**，而单位金币价值上升。净效应是 `Σ_i φ(μ_i/σ)/σ`。实算：

| `\|μ_i\|` | σ=766 | σ=200 | 方向 |
|---:|---:|---:|---|
| 0 | 0.0521 | 0.1995 | **升 3.83×** |
| 100 | 0.0516 | 0.1760 | 升 3.41× |
| 200 | 0.0503 | 0.1210 | 升 2.40× |
| **400** | 0.0454 | **0.0270** | **降 0.59×** |
| 600 | 0.0383 | 0.0022 | 降 0.06× |
| 800 | 0.0302 | 0.0001 | 降 0.00× |

`φ(μ/σ)/σ` 在 **σ = |μ|** 处取极大（`d/dt[t·e^{-t²/2}]=0 ⇒ t=1`）⇒ **σ 收窄只对 `|μ_i| < 约 300` 的队有利，对远离 0 的队有害。**

⇒ **① 与 ② 必须联合解读，不得分开报。** 斜率的高低完全由「`μ` 分布位置」与「`σ` 收窄」两者的相对关系决定；若 `fd47ea6` 对多数队的 `μ_i` 普遍在 −400 以外，则 σ 收窄反而**压低**斜率。

## 4. 联合含义（请在报告里点出）
被动局胜率 **50.9%** 与换代前的 **51.1%** 几乎相同 ⇒ **公开位换代（快 18 倍）的收益目前不可测**。这与「延迟不是病灶」的既有诊断**一致而非矛盾**。
⇒ **若延迟不产生胜率，margin 就是唯一杠杆。** 故：
- 斜率落在 **0.10–0.25** ⇒ margin 杠杆有效，小额候选（`Clut_k6_stay` 级，约 40 金 ⇒ 约 4–10pp）值得全部收下；
- 斜率落在 **0.04–0.07** ⇒ **我们同时失去延迟与 margin 两条路**，那时守成是唯一正确策略，且必须重新寻找非 margin 型杠杆。

## 5. 方法学纪律（本轮新增，已入 `AGENT.md`）
1. **军规 33 升级**：零信号干跑必须覆盖**选样**，不只是**裁决**（判例：`None == False` 使自博弈守卫失效，对手数由 12 虚增为 106；污染方向是「变多」，而「样本比预期大」在直觉上像好消息）。
2. **准入门是可重标定量**：`max(2SE, |标定场−均匀场|)` 是**唯一准入判据**；`pp/金` 是**战略记账、不参与准入**（价值线性过原点 ⇒ 价值尺度不产生阈值）。
3. **flip 计数是被估量，密度法是低方差估计量**（带宽偏倚实测 6%，且方向保守 —— 刚输的局比刚赢的更密，±200 内 23 vs 11）。
4. **斜率对「每对打几局」免疫**（`sim/verify_winrate_invariance.py`：规则 a 极差 0.03pp / 规则 b 涨 1.72×）；唯一赛制相关量是 `σ_single`。
5. **新通则**：**纠正一个错误结论时，保留它成立的条件域，而不是删掉它。** 判例即上一条 —— 我原先的 `1/√N` 折扣在「每对按 N 局多数决胜」规则下**是对的**，把该条件域留在模块里，才防得住下一个人在别的赛制下错误外推免疫性。
