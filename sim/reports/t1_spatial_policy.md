## 0. 一页结论

所有者的观察是**一半证实、一半证否**，而证否的那一半在追查中换来了一个**更有价值的东西**：周期是**行为**，快照是**原因**。

| 所有者的原话拆分 | 裁决 | 决定性统计量 |
|---|---|---|
| 「两个机器人分别负责半边」 | **按字面证否；弱化版证实** | 固定半边轴准确率 0.5648±0.0366（阈值 0.75，整局标签翻转 p=0.375）；但 within-game OVL 0.4399±0.0366 vs **跨局配对 null** 0.4935 ⇒ z=−2.553, p=0.0145 |
| 「有规律的（固定周期）」 | **证否** | 10 条单位序列中**击败双 null 的 = 0**；峰周期 29.6/14.6/17.8/81.1/13.0/21.1/96.8/96.8/57.7/15.3（均 44.4±11.2，sd 35.3）；Rayleigh 相位锁 p=0.841(uniform)/0.849(interval-shuffle)；**无偏金币通道**配对 ACF 最大跨队差仅 0.0628±0.0096（n=156 局） |
| 「中心 → 周围 → 中心」的**交替与振幅** | **证实，且很大** | 严格 DP 双侧界：外圈 d≥5 份额 ∈ **[0.2740, 0.4831]**（±0.0136），均值环距 ∈ [3.451, 4.782]，转折环 **d=8** |

**真机制**：T-1 在读 `GameInput.snapshot`。而我方 `fd47ea6` **完全不读该字段**。

**最大的、也最干净的缺口不是周期，是振幅**：

|---|---|---|---|
| **T-1** | **[27.4%, 48.3%]** 严格界 | [3.45, 4.78] | model 87478；map1；探针语料 5 局；T-1 净 2344–2622（无干扰）；bias_ratio(该语料) 0.929 |
| **我方 `fd47ea6`** | **5.06% ± 0.14%** | **2.715 ± 0.009** | 先手臂；模拟器 160 局；**100% 自观测、零迷雾偏倚** |
| 我方 `fd47ea6` | 4.41% ± 0.13% | 2.743 ± 0.008 | 后手臂；同上 |
| rikka 公开位 `player47` | **1.8%**（近无偏） | 2.32 | 17 局全 map1；bias_ratio **0.996±0.054** ⇒ naive 即真值 |

⚠️ **这不是一次合法相减**（T-1 在平台引擎/真 NPC/对 probeobs，我方在模拟器/拟合 NPC/对自己）。但差距是 **5.4×–9.5×**，远大于任何合理的引擎产物；且模拟器 NPC **偏中央**，若有偏则是把我方**往外推** ⇒ 真实差距只会更大。**方向可用，数值不可作差。**

## 1. 第 1 步：四项裁决（详）

**共同前提**：目标 = Tiuntled-1 / `player163` / model_id 87478。板 17×17，中心 (8,8)，`d = chebyshev`，中央 9×9 = d≤4，外圈 = d≥5。剔除轮 0–3（延迟预热）。

### 1.1 三套语料及其不可互换性

| 语料 | 局 | T-1 可见率 | T-1 净分 | 用途 |
|---|---|---|---|---|
| **clean 探针**（主） | `172219/171747/172186/171719/172187` | 单位 0.854–0.898；双 0.294–0.46 | **2344–2622** | 唯一可测**自然策略**的语料 |
| **高可见跟踪**（次） | `162570 trk1`/`162578 warden2`/`159175 vch23`/`162660 stalk1`/`162632 warden3` | 双 0.692–0.986 | **305–1274** | 仅作**结构**存在性检查 |
| **无偏金币**（判 C 的承重通道） | 158 局全部 T-1 对局 | **100%**（per-unit `gold` 无论可见与否） | 混合 | 判周期性 |

🔴 **跟踪语料证明 T-1 的空间策略是对手依赖的**：被我方跟踪骚扰时，均值环距升到 5.0–6.8、两单位退到对角，净分塌到 305–1274。**因此跟踪语料的任何量不得与 clean 语料相减**（六条件之「同对手」）。这本身是一条独立发现：*T-1 会被贴身施压逼出中央*。

### 1.2 P 分区

- **按字面（各守固定半边）证否**：单一全局 (轴, 符号) 的平均准确率 **0.5648 ± 0.0366**，预注册的「固定半边」阈值是 0.75，整局标签翻转精确 null 给 **p = 0.375**。逐局最优轴各不相同（`anti` / `diag` / `row`），符号也翻转（−1 / +1）。
- **弱化版（两单位互相回避，轴逐局可变）证实**：within-game OVL **0.4399 ± 0.0366** vs **跨局单位配对 null 0.4935** ⇒ **z = −2.553, p = 0.0145**。
- ⚠️ **我最初用的 null 是错的，已作废并记录在案**：轮内单位标签置换 null 在**零信号下就会报"分区"**（两条独立有界随机游走给 OVL 0.00 vs 置换 null 0.54，**z = −19**）。它检验的是「空间局部化」，不是「分区」。我先前上报的 z = −0.67…−5.85 与 z = −22…−36 **全部由该无效 null 产生，作废**。合法答案是上面的 z = −2.553。
- **偏倚方向（保守）**：共同可见要求两单位**同时**落在我方雾窗内 ⇒ 过采「两单位靠得近」的轮 ⇒ 把 OVL 推**高**、把轴准确率推**低**，即**两个方向都不利于分区**。故「回避成立」是保守结论；而「固定半边不成立」这一否证相应被**削弱**。
- 跟踪语料：within_ovl 0.0598 vs 跨局 null 0.0821，z = **−0.572**（不显著）—— 因为骚扰把两局的两个单位都推到极端，跨局配对同样得到低 OVL。**「近乎完全分离」的直觉在合法 null 下不成立。**

### 1.3 C 周期 —— 证否

- **无偏金币通道（承重）**：逐轮收入配对 ACF，与**同局对手**配对（消除环境），n=156 局，跨队最大绝对差 **0.0628 ± 0.0096**，出现在 lag 1（T-1 0.1665±0.0087 vs 我方 0.1037±0.0061）。**lag 3–60 无任何周期结构。**
- **轨迹通道**：10 条单位环距序列中，**击败 AR(1)-matched + 有界随机游走双 null 的 = 0**。峰周期在 13.0–96.8 间散乱（均 44.4 ± 11.2，sd 35.3）。
- **相位锁**：Rayleigh R_max 0.120，p = 0.841（uniform）/ 0.849（interval-shuffle）。
- **出击间隔近乎无记忆**：CV = **0.978**（指数分布 CV = 1）。
- **唯一检出的周期是环境的**：绝对时钟 mod 20 **p = 0.0199**，mod 12 p = 0.530。mod-20 就是**炸弹整套重采样**（实测 284 次变更全部落在 r mod 20 == 0，off-wave = 0；模拟器侧 240 局每局恰 24 波、直方图 `{0: 5760}`）。⇒ **把 mod-20 读成"T-1 的周期"会是一次典型的环境混杂。**
- **环境标定（供别线设门）**：我方**已知无周期**的 `fd47ea6`，其环距序列在 4–40 带的 LS 峰功率 = **13.79 ± 0.37**，峰周期 28.0 ± 0.61；同脚本白噪基线 = **6.06 ± 0.09**。⇒ **「无周期」在本环境下长得像 LS 峰约 14、周期约 28。** 任何周期主张必须击败 ~14，而不是击败白噪 6。我方收入序列 5.59 ± 0.09（低于白噪）。`ls_power_at_period_20` 仅 2.83（环距）/1.15（收入）⇒ 炸弹时钟**不主导**我方序列。
  ⚠️ 该 13.79 与 `t1_spatial_policy.json` 里 T-1 的 `peak_power_mean = 0.1357` **归一化不同、不可相减**（两个脚本各自定义）。跨脚本比较必须重算。
- **偏倚方向（反向，须记住）**：探针在 T-1 长距外出时**优先丢失**它（探测概率随 d 单调下降），缺口正好集中在任何径向周期的两个极值处 ⇒ **会衰减真周期**。故轨迹通道的 null 结果是**弱证据**；承重的是不受此影响的无偏金币通道。

### 1.4 A 振幅 —— 证实，且这是真正的缺口

- clean 语料 naive 环分布（可见子集）：d0 1.20 · d1 6.07 · d2 21.77 · d3 27.75 · d4 13.57 · d5 9.56 · d6 6.65 · d7 9.75 · d8 3.68（%）
- naive 外圈 29.66%（局间 SE 0.99pp，块 bootstrap SE 1.53pp），naive 均值 d = 3.728 ± 0.046
- **严格双侧界（分层图可行性 DP，非模型）**：外圈 ∈ **[0.2740, 0.4831]** ± 0.0136；均值 d ∈ **[3.451, 4.782]**。**转折环 = d = 8** ⇒ 是**真跨区远征**，不是中央区内扫掠。
- 未截断的出击峰环直方图 d5:33 / d6:22 / d7:17 / d8:19 ⇒ **约 40% 的出击摸到 d≥7**。
- ⚠️ **我先前把 naive 29.7% 称为「硬下界」是错的**：严格下界是 **27.4%**（DP 允许被遮轮落在中央）。已改。
- **HT 估计器已实测会过校正，不作点估计**：覆盖率 0.996 的 `162570` 仍虚增均值 d **+0.39**（此时几乎无可校正），覆盖率 0.836 的 `162632` 虚增 **+2.50**。「环内均匀」假设为假。
- **无模型的方向证明（不需要任何加权）**：per-unit `gold` 100% 记录 ⇒ 未观测轮收入 = 总额 − 已观测，**精确**。得 **未观测 2.788 vs 已观测 2.314 金/单位轮，比 1.219 ± 0.089（n=5 局，局内配对，约 2.5σ，4/5 局 >1）** ⇒ **迷雾遮住的是 T-1 更富的轮次**，与外向压制同向。
- **T-1 的外圈时间不是成本**：收入对环距**平坦** —— 中央 d≤4 = 2.348 ± 0.149 vs 外圈 d≥5 = 2.233 ± 0.206，差 **−0.115 ± 0.255 = −0.45σ**。

### 1.5 Φ 反相 —— 证否

corr(d0,d1) = **−0.0139 ± 0.0325**；跨局配对 null 均值 0.0294、sd 0.103，z = −0.42、p = 0.317；逐局标签全为 `none`。
我另测了「旋转轨道」这一更精巧的可能（它会同时躲过固定轴检验）：两单位夹角 **78–92°**，与「u0 取 r 轮 / u1 取随机另一轮」的打乱 null **不可区分（z = −1.69…+0.22）**；角速度 −4.4…+1.6 度/轮、SE ≈ 1.8、符号在单位与局间不一致。**无轨道、无相位协调。**

### 1.6 为什么所有者会看到「有规律」

T-1 每单位每局约 **25 次** d≥5 出击、平均每次约 **6 轮**、约 30–48% 的时间在外圈、振幅摸到 d=8。**大振幅、高频率、无固定周期**的交替，在录像上与周期运动**在感知上不可区分**。⇒ 所有者看到的**行为是真的**，「有规律」是**归因错误**。这类误判无需假设任何人犯错，只需要人眼对准周期信号缺乏检验能力 —— 这正是要先跑裁决器再下结论的理由。

## 2. 真机制：`Snapshot`

### 2.1 语义（回源 + 792 个真实平台快照实测）

源：`sim/engine.py:790-825`（`_make_snapshot`）。

| 字段 | 语义 | 证据 |
|---|---|---|
| `snapshot_valid` | **恰好每 5 轮**：`round>0 && round%5==0` ⇒ 轮 5,10,…,495 | 792 快照违规 **0**；mod5 直方图 `{0: 792}` |
| `window` | **`[T−5, T−1]`，不含当轮** | 违规 **0/792** |
| **`gold_remaining`** | **实时**：轮 T 轮首 `state.ground` 逐区求和，**零滞后**、与迷雾无关 | `engine.py:806-810`；3960 次区域检查「可见地面金 ≤ 上报值」违规 **0** |
| **`occupants`** | **实时**，计入双方 4 单位 **+ 全部 7 NPC = 11** | `engine.py:812-817`；**495/495** 快照总和恰为 11 |
| `enter`/`leave`/`gold_collected` | **滞后**窗口聚合 `[T−5,T−1]` | `engine.py:795-803` |
| ⚠️ `gold_generated` | **窗口不同**：`[T−4, T]`，**含当轮** | `engine.py:804-805` |

**两个坑**：① 六字段**不共用一个窗口**，假设同窗必静默算错。② `occupants` 约 **64% 是 NPC 信息**（7/11），拿它做「避开对手」会读错对象。
⚠️ 以上是**模拟器实现**语义（其快照对官方日志 8910/8910），我另用 792 个真实平台快照复核了 cadence 与 window。**不是官方规格文本。**

### 2.2 T-1 在用它（效应温和，前提齐全）

**设计（几何按构造配平，null 恰为 50%）**：对每个（单位, 快照 T），取与该单位**近等距**的臂对（`|d_a−d_b| ≤ 1`，切比雪夫到臂最近格）且 `gold_remaining` 相差 ≥ 阈值；结果 = 随后落在**更富那臂**的份额。

| 主体 | 更富臂份额 | n | z vs 50% | 前提 |
|---|---|---|---|---|
| **T-1** gap≥15，T+1..T+5 | **58.8% ± 4.5** | 119 | **+1.96** | model 87478；map1；clean 探针；bias_ratio 0.929 |
| T-1 gap≥40 | 52.8% ± 6.9 | 53 | +0.41 | 同上 |
| **T-1 零信号干跑**（局内打乱 gold 向量，保留几何与轨迹） | **46.3% ± 4.8** | 108 | −0.77 ✅ | 正确居中 |
| 我方**旧混合**构型 gap≥15 | 57.6% ± 2.3 | 453 | **+3.28** | ⚠️ 混合构型语料、3 图各 5 局、非 `fd47ea6` |
| **rikka 定制位** `g47v220m*` gap≥15 | **93.2% ± 3.8** | 44 | **+11.36** | 3 图各 5 局；恒后手；263μs–11ms；bias_ratio **2.173±0.609** |
| rikka 公开位 `player47` | 18.7% ± 4.1 | 91 | 不可判（功效不足） | 17 局全 map1；bias_ratio 0.996±0.054 |

无条件设计（null 25%）给一致的效应量：T-1 argmax 臂 **32.0% ± 1.6**（n=881），时间反转 23.8% ± 1.4，offset 展开 −8..−3 为 20–25%、0..+6 为 30–34%、+11 衰回 25%（「响应后变陈旧」，与实时信号每 5 轮刷新自洽）。

**两条必须撤回的**：
1. **「剂量反应」撤回。** 控制几何后 gap≥40 反而更弱（52.8% ± 6.9）。原先的上升是几何产物。
2. **不得用「前向 − 时间反转」之差当效应量。** 配对设计下安慰剂落在 **36.6% ± 4.2（z=−3.23）**，**显著低于 50%**，因为**机械反向因果**：单位待过的臂被它自己采空 ⇒ 事后必然是"更穷"那方。合法零点是**打乱干跑 46.3% ± 4.8**。
3. **`probeobs` 不是合法特异性对照**（我先前误用）：它**设计上跟随 T-1**，继承其目的地，峰在 offset +6 而非 T-1 的 +2。站得住的只有打乱干跑与几何配对。

**站得住的效应量**：两套设计一致，约 **+7 ~ +9pp**。判为「**真实但温和**」，不是决定性。

**`occupants`**：T-1 **未检出**规避拥挤臂 —— 距离配对下落在较空臂 **50.0% ± 5.5（z=+0.00）**，零信号打乱 46.6% ± 4.9。n=82 ⇒ **不可判、倾向无**（只能排除 >约 11pp 的效应）。

### 2.3 我方对该通道结构性失明

`src/player.cpp` 只读 `GameInput` 9 个字段中的 4 个：`round` / `grid` / `my_units` / `my_units_gold`。**`snapshot` 零命中**（大小写不敏感计数 = 0），`visible_npcs` / `visible_enemies` / `gold_opp` 亦零。

🔴 **但这不是处女地**：我方**旧构型**的快照响应（57.6% ± 2.3）与 T-1（58.8% ± 4.5）**统计上不可区分** ⇒ 该传感器**历史上被用过、后来被移除**（`player.cpp:18` 头注「快照远征调度已下岗」）。正确说法是「**`fd47ea6` 失明，我方前代不失明**」。**这实质降低先验**：重开之前必须回源查清「当年为什么拿掉、拿掉时的配对增益」。

### 2.4 可移植性：只有快照那条过关

运行时 `GameInput` **没有 token 层**（只有带雾 `grid`：−5 雾 / −3 弹 / −1 障 / 0 空 / ≥1 金）。**那 20 个 token-2 热点格在运行时不可见**，是观战日志第 2 行的产物。

| 路线 | 需要地图专属表？ | 能否过「不保证沿用当前两张地图」 |
|---|---|---|
| 热点表（20 个 token-2 格） | **要**（按图硬编码；且 `sim/maps.json` 的 map3 只有 7×7、token2 = 0） | ❌ |
| **快照 argmax 区域** | **不要**（风车几何固定，`engine.py:84`，与地图无关） | ✅ |

补一条侧证：T-1 站在那 20 格上时收入 **5.603 ± 0.596** vs 别处 2.183 ± 0.136 ⇒ **+3.420 ± 0.611 = +5.59σ**，5.9% 的观测轮贡献 **14.4%** 的总金。它确实在吃热点 —— 但它**不可能知道格号**，只能靠快照把它送到正确的臂，再交给自己的 5×5 接手。（⚠️ 该 +5.59σ 有「停留才被探测到」的向上偏倚；但 §1.4 的闭账显示**未观测轮更富**，说明该偏倚不主导。）

## 3. 与两个历史判负的精确区分

| | 振幅 / 到站 | 远征态占比 | 触发方式 | 结局 |
|---|---|---|---|---|
| **外圈热点远征** | 走约 6 轮到**固定**热点，到站中位采金 **0** | **88.6%** | **排班（盲）** | **−477** |

### 8.2 一条不依赖任何位置统计量的独立证否（因此免疫迷雾偏倚）

### 8.5 结论与一处**未识别残差**
「一常驻一外出」**证否** ⇒ 27–48% 的外圈时间是**两个单位对称地各自外出**实现的。

⚠️ 但由此**不能**直接推出「外圈整类关闭」。存在一个**实测残差**：T-1 两单位各约 30% 时间在外圈且**外圈收入率与中央无差异**（−0.115 ± 0.255），而我方把锚点移出去**先手臂亏 52–57**。⇒ 残差是**「在外圈的采集效率」**，不是「去不去」、也不是「谁去」。两边选靶器都只读自己的 5×5（我方已证，T-1 从不买视野），故该残差**目前没有机制解释**。

**本残差不登记为候选**，理由是纪律而非谦虚：① 它只有"两个数不一致"这一个事实，未经任何测量；② 它正是「多源汇合不等于因果」那条教训的形状（本会话已因「角色分化」叙事踩过一次：三条观察皆真、拼出的原因是错的）；③ 要成为候选需要一个**识别设计**（例如同批 seed 强制把我方单位置于外圈，测其实收率 vs T-1 的 2.23，同顺序同图同语料），而该设计尚不存在。
