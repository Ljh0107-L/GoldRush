## 演进主线(410 -> 250 -> 210)

- **信封方法论**(用户定向): 先写极简正确内核量出 200ns 装得下什么, 算法从预算向上生长
- v5a 信封首测 500ns/38位点 -> **ctz 哨兵惨案**(`sel|1u` 恒补 bit0 -> 目标恒=窗口左上角,
  收入 168-364; 调试构建+真实输入回放定位) -> v5b 修复后 410-440
- v5c 位点大清剿(38->15): 无条件行片写/算术级联/cmov 双钳 -> 370/290
- v5f 受阻轮单步自愈(steer3 蒸发): **250-260/340-400 + 收入全系最高** = 冠军定格
- v5r 板块手术(执行指令 1288->761): 210/250 —— 之后收入三连试未愈, 轨线冻结

## 负结果军规(每条都付过学费)

1. **冻结红利**: v5n 系"240/280"部分是单位死锁少跑内存的假快 —— 延迟读数必须配行为体检
2. **v5n 无逃逸回落死锁**: 墙口袋双方向全堵 -> 永久 STAY(147061 三发探针定位); 逃逸是保命装备
3. 掩码化改写必须带行为回归(pair_diff/收入批) —— 纯周期验收会放行语义灾难(ctz 案)
4. unroll 展开 = 静态位点翻倍 = 平台负优化(三次验证)
5. v47 教训: 门控分支的价值是省功, 不只是省位点
6. Clang 本地胜平台负(位点 21>13) —— 位点>指令数, 第四次验证
7. 金额加权(v5v/w)+90ns 判负: 富度差在大堆驻留深度, 不在目标选择层(对撞局 146845 破译)
