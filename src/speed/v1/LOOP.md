# speed/v1 — 算法流程（每轮决策 loop）

> 曾名 v5f。现役总冠军：P50 250-260ns / P90 340-400 / 收入 1550-1900。
> 设计信条：信封方法论——先量出 200ns 装得下什么，算法从预算向上生长。
> 三元门禁：本地计算 ≤250 周期 / 分支位点 ≤15 / .text ≤4KB。

## 入口与安全壳

```
moveDecision(in)
  └─ try { sanitize(decide(in)) } catch(...) { SAFE_OUT }   // 判负红线兜底
```

`sanitize` 全 cmov 钳位（actions∈[0,4] / k∈[0,6] / order∈{0,1} / vp∈[0,2]），零分支位点。

## 每轮 decide 流程

```
┌ 0. 行前置装载（进函数第一件事，早于一切账务）
│    双单位各 5 条 5×5 窗口行 → AVX2 rowbufs[2][5]
│    目的: 10 条 cache 行的 miss 最早并行发射，搬运延迟藏进后续标量账务的阴影里
│
├ 1. 新局检测: round ≤ last_round → memset 状态
│    bpw = 墙|边界哨兵位图（+1 偏移，外圈全 1）; bombbit = 炸弹位图
│
├ 2. 炸弹波清: round % 20 == 0 → bombbit 清零（弹记忆即弃，等本轮扫描重建）
│
├ 3. 对每个单位 u ∈ {0,1}:（两单位每轮都全流程，无轮换）
│
│  3.1 富度门: rich = 全 1 掩码 ⇔ 持金 ≥ 100
│      穷单位弹透明（烧 10%×0=0，合法优化）; 富单位把弹并入阻挡
│
│  3.2 掩码扫描（零分支）
│      rowbufs SIMD 比较（>0 金 / ==-1 墙 / ==-3 弹）+ movemask
│      → 25 位掩码 goldm / wallm / bombm（窗口越界位由 colv/rowok 掩掉）
│      墙/弹无条件 5 行行片写进 bpw/bombbit（空片写=无操作，换掉 if）
│
│  3.3 目标选择: 最近金格，否则锚点
│      环掩码 RM1..RM4（按切比雪夫环距分层）+ 掩码级联选最近非空环
│      → ctz 取格（sel 仅在全空时补位——`|1u` 恒补 bit0 是 v5b 崩盘元凶）
│      无金: 回落分区锚点 u0→(6,6) / u1→(10,10)（中心 9×9 驻守）
│
│  3.4 站金（d==0）: 折返双吃
│      四邻通行掩码 pm → ctz 取首个方向 a; acts = [a, a^1, ...]
│      出格再回格，重复收脚下 35% 残值（65% 链式拾取）
│
│  3.5 行进（d>0）: LUT 三步导向
│      dr/dc 钳进 [-3,3]（远目标前 3 步与逐步串行同构）
│      LUT（constexpr 预算的 7×7×3 行优先模拟）给出 3 步动作+逐步累计位移
│      pass01 并行验证 3 个途经格（非墙 & 非富弹 & 非队友格）
│      ├ 全通过 → 3 步照走; 早到（d<3）用掩码写补折返双吃（零位点）
│      └ 受阻（罕见）→ steerStep 单步谨慎（长轴优先 → 短轴 → escapeStep
│        冷逃逸，禁回头格），其余 STAY —— 下轮重扫自愈（steer3 全链已蒸发）
│
└ 4. 输出装配: k=3; order=持金多者先走（保护大户先手）; vp=0（不买视野）
```

## 状态（State，~100B 单 cache 行对齐）

| 字段 | 作用 |
|---|---|
| `bpw[19]` | 墙\|边界哨兵位图（持久累积，仅新局清） |
| `bombbit[19]` | 炸弹位图（每 20 轮波清） |
| `last_r/last_c[2]` | 上轮位置（逃逸禁回头） |
| `last_round` | 新局检测 |

## 为什么长这样（对应军规）

- **无条件行片写 / 掩码级联 / cmov 双钳**：平台成本 ∝ 分支位点数 × 冷前端回热，位点 > 指令数（四次验证）。
- **受阻只走单步**：v5f 定格胜招——串行导向链蒸发后 250ns，受阻轮下轮自愈，行为无回归。
- **弹按持金气门**：一条 AND 替代双位图+护栏+波重建全家桶。
- **无视野/无矿堆缓存/无敌情**：都在预算外砍掉；开题清单里按期望值逐项评估加回。
