# speed/v1 — 算法流程（每轮决策 loop）

> 现役总冠军（2026-08-09 二次加冕，曾名 sv_g11）：**P50 中位 200（读数 170-230）/ P90 292 / 收入中位 1515**。
> 对 T-1 先手 427/500——latency 战役收官之作。上一代 g5nd：230/340，1568。
> 前任 v5f（本源码去 NS6 flag 的默认形态）：255/350，1656。八个 NS6 flag 见 Makefile。
> 设计信条：信封方法论 + **指令数即延迟**（壳40 + 载荷~2/条 + 指令×0.2ns，8.9 探针定标）。
>
> **v5f → 现役的架构增量**（全部 pair_diff 逐位对账或收入批量验收）：
> - **NS6W 烘焙墙**：map1 的 40 墙是常量，直灌 bpw 初始化——墙提取/墙写全部下线（-92）。
>   ⚠ 换图必须重烘焙 BAKED_W1。
> - **NS6B3 弹窗 rows3**：炸弹只在 ±1 行记账（-59，弹视野收窄换指令）。
> - **NS6X pext 环级联**：goldm 按环优先级 pext 重排，一次 ctz 替代五级掩码级联（-33）。
> - **NS6F 折返预折 LUT**：早到折返（d<3）在 constexpr 表内预折叠，运行时掩码块删除。
> - **NS6O/C2/C3**：免 SAFE_OUT 拷贝 / 钳位与除模 LUT / 扫描边缘常量表（cb/lsh/colv=sc 纯函数）。
> - **NS6FU 装载-扫描融合**：探针证明载荷是热的→前置装载存在理由消失，rowbufs 溢出税整体下线。
> - **NS6NT 队友检查下岗**：pass01 比较链坍塌（-79 含溢出连带），撞位实测 0 轮（锚点天然隔离）。
> - **NS6NS/NS6NC**：sanitize 与入口钳位军械库下岗（输出/输入可证合法，pair_diff 保真）。
> - **NS6RT 开局烘焙路线**：BFS 4 轮出角常量（旧墙口袋爬行 9-10 轮），盲轮+位置吻合才生效、
>   漂移自弃；门控分支形态（掩码版 +73 指令判负——定律 3：低频功能用门控省功）。
> - 判负未入列：NS6D2 二连体展开（-64 指令输给 +1.7KB .text 的 icache 税）、PGO（平台无感）、O2。
>
> 下述流程骨架两代通用（增量只动实现层，不动决策语义）：

## 入口与安全壳

```
moveDecision(in)
  └─ try { decide(in) } catch(...) { SAFE_OUT }   // 判负红线兜底(try/catch 永不下岗)
```

现役构建（NS6NS）已退役 sanitize 钳位——输出全路径可证合法（pair_diff 保真）；
去 flag 的 v5f 形态仍走 `sanitize(decide(in))` 全 cmov 钳位。

## 每轮 decide 流程

```
┌ 0. （已融合）前置装载在 NS6FU 中退役——探针证明输入行是热的，
│    载荷改在各单位扫描循环内就地发射（v5f 形态仍保留独立预载块）
│
├ 1. 新局检测: round ≤ last_round → memset 状态
│    bpw = 墙|边界哨兵位图（+1 偏移，外圈全 1）**| BAKED_W1 烘焙墙直灌**; bombbit = 炸弹位图
│
├ 2. 炸弹波清: round % 20 == 0 → bombbit 清零（弹记忆即弃，等本轮扫描重建）
│
├ 3. 对每个单位 u ∈ {0,1}:（两单位每轮都全流程，无轮换）
│
│  3.1 富度门: rich = 全 1 掩码 ⇔ 持金 ≥ 100
│      穷单位弹透明（烧 10%×0=0，合法优化）; 富单位把弹并入阻挡
│
│  3.2 掩码扫描（零分支，NS6W 轻版）
│      就地载入 5 行 + AVX-512 k 掩码比较（>0 金全 5 行 / ==-3 弹仅 ±1 行 NS6B3）
│      → goldm 25 位 / bombm 15 位（越界位由 colv/rowok 掩掉；墙不再提取——烘焙表已知）
│      弹行片写进 bombbit（3 行）；墙写全线退役
│
│  3.3 目标选择: 最近金格，否则锚点
│      环掩码 RM1..RM4（按切比雪夫环距分层）+ 掩码级联选最近非空环
│      → ctz 取格（sel 仅在全空时补位——`|1u` 恒补 bit0 是 v5b 崩盘元凶）
│      无金: 回落分区锚点 u0→(6,6) / u1→(10,10)（中心 9×9 驻守）
│
│  3.4 站金（d==0）: 折返双吃
│      四邻通行掩码 pm → ctz 取首个方向 a; acts = [a, a^1, ...]
│      出格再回格，重复收脚下 35% 残值（65% 链式拾取）
│
│  3.5 行进（d>0）: LUT 三步导向
│      dr/dc 钳进 [-3,3]（远目标前 3 步与逐步串行同构）
│      LUT（constexpr 预算的 7×7×3 行优先模拟）给出 3 步动作+逐步累计位移
│      pass01 并行验证 3 个途经格（非墙[烘焙+累积] & 非富弹；队友检查已退役 NS6NT——
│         锚点分工使撞位实测 0 轮，引擎记 4 + 自愈兜底）
│      ├ 全通过 → 3 步照走; 早到（d<3）用掩码写补折返双吃（零位点）
│      └ 受阻（罕见）→ steerStep 单步谨慎（长轴优先 → 短轴 → escapeStep
│        冷逃逸，禁回头格），其余 STAY —— 下轮重扫自愈（steer3 全链已蒸发）
│
└ 4. 输出装配: k=3; order=持金多者先走（保护大户先手）; vp=0（不买视野）
```

## 状态（State，~100B 单 cache 行对齐）

| 字段 | 作用 |
|---|---|
| `bpw[19]` | 墙\|边界哨兵位图（持久累积，仅新局清） |
| `bombbit[19]` | 炸弹位图（每 20 轮波清） |
| `last_r/last_c[2]` | 上轮位置（逃逸禁回头） |
| `last_round` | 新局检测 |

## 为什么长这样（对应军规）

- **无条件行片写 / 掩码级联 / cmov 双钳**：平台成本 ∝ 分支位点数 × 冷前端回热，位点 > 指令数（四次验证）。
- **受阻只走单步**：v5f 定格胜招——串行导向链蒸发后 250ns，受阻轮下轮自愈，行为无回归。
- **弹按持金气门**：一条 AND 替代双位图+护栏+波重建全家桶。
- **无视野/无矿堆缓存/无敌情**：都在预算外砍掉；开题清单里按期望值逐项评估加回。
