# strategy/v1 — 算法流程（每轮决策 loop）

> 曾名 v42（旧号 v2，2026-08-07 版本号重置后定名 v1）。
> 策略轨冠军：P50 700-790ns / 收入 1660-2120，双扫矿堆农，首斩力行 1958:1234。
> 现役编译形态：`-DNS3DUAL -DNS3FILL0 -DNS3NOPLAN`（双扫 / 尾步填充关 / 计划缓存关）。
> 立项依据：赢家收入 64-78% 来自暴击轮，全是矿堆农；速度本身是收入引擎。

## 入口与安全壳

```
moveDecision(in)
  └─ try { sanitize(decide(in)) } catch(...) { SAFE_OUT }
```

## 每轮 decide 流程

```
┌ 0. 行前置装载: 双单位各 5 条 5×5 窗口行 → AVX2 rowbufs（miss 早发射）
│
├ 1. 新局检测: round ≤ last_round → memset 状态（bp 哨兵边界重建）
│
├ 2. 炸弹波清: round % 20 == 0 且已知有弹 → 从 bp 抹掉 bombbit 再清位图
│
├ 3. 扫描（NS3DUAL: 两单位背靠背全扫，MLP 重叠）
│    每单位: SIMD 比较+movemask → goldm / wallm / bombm 25 位掩码
│    ├ 墙 → 并入 bp（导向用唯一地形真值: 墙|弹|边界）
│    ├ 弹 → bombbit + bp，置 banybomb 全局门
│    └ 矿堆登记: 窗口内 v≥5 的格写入 16 槽直映射缓存
│      （坐标 pr_/pc_ + 存量 pv_ + 时间戳 ps_ + 活堆掩码 plive）
│      —— 离开视野后矿堆仍被记忆，是"矿堆农"的原料
│
├ 4. 对每个单位 u ∈ {0,1}:
│
│  4.1 窗口金格打分（只走 goldm 置位格）
│      score = (v×2 + 四邻金之和) × REC[曼哈顿距]
│      簇加成: 堆积区一格常连着一片; REC 倒数表免除法
│
│  4.2 目标三级级联（掩码化，无分支）
│      窗口最优金格
│        > 活矿堆（缓存里 ≤~40 轮的新鲜堆，打分 pv×(64−2d)，过期顺手清;
│          u0 只吃中心 9×9 的堆——守先手红利; u1 全图收堆——矿堆农本职;
│          到达即从缓存摘除）
│        > 巡游路点（各 4 点循环: u0 中心环 (5,6)(5,10)(10,10)(10,6)，
│          u1 外环 (3,3)(3,13)(13,13)(13,3)——外圈 31% 刷新无人吃会堆积）
│
│  4.3 站上目标（d==0）: 折返双吃（出格 a + 回格 a^1，收 35% 残值链）
│
│  4.4 行进（d>0）: steerStep×3 掩码展开链
│      每步: 长轴优先 → 短轴替补 → escapeStep 冷逃逸（禁回头格）
│      到目标即余步 STAY; 早到金格 → 余步改折返双吃
│
│  4.5 卡死解困: 位置连续 2 轮未动且首步 STAY → stuckEscape 强制迈步
│
│  4.6 防漂移护栏（banybomb 且持金 ≥300 才进，门控=省功）
│      行位图 7 行并查近弹 → 模拟 3 步路径，撞弹则从该步起截断为 STAY
│
└ 5. 输出: k=3; order=持金多者先走; vp=0（视野触发器两版全哑，仍是开题）
```

## 状态（State，~160B）

| 字段 | 作用 |
|---|---|
| `bp[19]` | 阻挡位图: 墙\|弹\|边界（导向唯一真值） |
| `bombbit[17]` | 炸弹位图（护栏与波清用） |
| `pr_/pc_/pv_/ps_[16] + plive` | 矿堆缓存（直映射哈希 `(r*31+c)&15`） |
| `patrol[2]` | 巡游路点下标 |
| `stuck[2]` / `last_r/c[2]` | 卡死计数 / 上轮位置 |

## 编译开关（现役形态之外全是实验闸门）

| 开关 | 现役 | 含义 |
|---|---|---|
| `NS3DUAL` | ✅ | 双扫（无被动单位；否则 active=round&1 轮换） |
| `NS3FILL0` | ✅ | 关尾步填充（STAY 步顺路捡金的填充逻辑） |
| `NS3NOPLAN` | ✅ | 关被动轮计划缓存（双扫下本就无被动轮） |
| `NS3VP` | ❌ | 盲轮买视野探针（两版触发器全哑，未转正） |
| `NS3LUT` | ❌ | 直线快路径实验 |
| `NS3MIN/BARE/PROBE/...` | ❌ | 消融/探针实验档 |

## 为什么长这样（对应判决史）

- **双扫替代轮换**：轮换制被动轮收入~0、罚站 62% → 双扫收入翻倍，策略轨冠军定格。
- **u1 外环矿堆农**：纯外环巡游判负（97% 时间只挣 165）；矿堆缓存把单位自然拽回有货的地方。
- **矿堆无争议**：先手权只裁决新刷金归属，堆积存量后手也稳赚——这是慢 500ns 仍能打的根基。
