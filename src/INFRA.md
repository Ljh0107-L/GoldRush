# INFRA.md — 平台成本模型（算法设计前必读）

> 两天 ~200 局探针与消融实验换来的定价表。设计任何新算法先在这里估 ns，再写代码。
> 数据截至 2026-08-09；正赛硬件如变，用 §5 的探针法重新标定。

## 1. 总公式

```
平台耗时 ≈ 壳 40ns + 输入行载荷 ×2ns/条 + 执行指令 ×0.2ns  (+ 罚则项, 见 §3)
```

实测校准（探针局 150579-150602，纯载荷空策略）：

| 载荷条数 | 0 | 4 | 6 | 10 |
|---|---|---|---|---|
| P50 | 40ns | 40 | 50 | 60 |

- **壳 40ns**：调用约定 + 平台计时开销，人人都付，不可优化。
- **载荷近乎免费**（~2ns/条）：输入 grid 是平台刚写完的热内存。"访存主导""前置装载重叠 miss"均已被证伪——不要为省载荷牺牲任何东西。
- **执行指令 0.2ns/条**（perf 差分标定，Zen4 ~4-5 IPC）：**这是唯一大额税基**。

现役校验：659 指令 → 模型 40+20+132 ≈ 192 → 平台读数 170-230（P50 中位 200）✓

## 2. 预算换算速查

| 你想跑多快(P50) | 指令预算 | 相对现役(659)的算法空间 |
|---|---|---|
| ~200ns | ~650 | 0（现役已满） |
| ~230ns | ~800 | **+150 条** |
| ~250ns | ~900 | **+250 条** |
| ~290ns | ~1100 | **+450 条** |
| ~400ns | ~1650 | **+1000 条** |

**对手档位对照**（先手权阈值，实测）：压 Tiuntled-1(180-220) 需 ≤650；压 Tundra(290)/rikka(350-400) 有 +450 空间；压量衡(570-640)/酱味大鸡(430-510) 有 +1000 空间。**算法/cost tradeoff 的核心决策 = 选择放弃对谁的先手权来换算法预算。**

常用操作单价（供估算，均为执行指令数）：

| 操作 | 指令 | ≈ns |
|---|---|---|
| 一次 AVX 行载+双掩码提取（扫描 1 行） | ~12 | 2.4 |
| 一次 pass01（位图通行查询） | ~5 | 1 |
| 一次 LUT/rodata 查表 | 1-2 | 0.3 |
| 一次 5×5 全窗扫描（5 行金+弹） | ~110 | 22 |
| 32 槽 pop-loop（ctz 迭代，视置位数） | ~8/位 | 1.6/位 |
| memset 76B（状态清理） | ~10 | 2 |
| 一个单位的完整决策管线（现役） | ~300 | 60 |

## 3. 罚则项（超出公式的隐形税，每条都有判例）

1. **分支位点税**：静态分支位点 ≤~13 时免费；超出后每个 ~12ns（冷前端回热）。
   恒预测方向的低频门控在低位点数下实测免费（开局行军案）。
   **规则：高频路径用掩码/cmov；低频功能（<5% 轮）用恒预测门控——掩码版每轮白付全款（开局行军掩码版 +73 指令判负）。**
2. **.text 税**：+1.7KB ≈ +15-20ns（icache 冷回填；二连体展开案：-64 指令输给 +2KB text）。
   现役 .text 4.7KB；新算法尽量复用现有代码路径。
3. **高频内联点乘数**：pass01 类被 ~15-20 处调用的内联函数，每 +1 op = 全局 +15-20 条（直读版判负案：+2 载荷 → +230 指令）。
4. **寄存器压力连带**：让变量活跃期跨越大代码块会触发溢出税（goldm 拖到循环尾 +73 案、双 rowbuf 10-ymm +140 案）。新增状态尽早折算成小标量。
5. **对手污染**：对手越重（策略型 5μs+），我方读数越高 +10-30ns；对撞时双方互相拖慢。
6. **rodata 冷表嫌疑**（未定谳）：热路径查表赚，P90 尾部疑似付冷载荷；表 ≤300B 未见危害。
7. **展开反税（8.9 mini2 案）**：`#pragma unroll 5` 滚回循环省 720B text——平台是回填瓶颈
   不是周期瓶颈，字节密度即延迟；军规 4 的机理确认。热路径体积刀序：-Os(decide 单函数) >
   滚环 > LUT 交错打包（fact/pdr/pdc 同索引三表并 1 行）> 链接器 `-z noseparate-code`+strip。
8. **保温线程封棺（8.9 warmA/B 判负）**：EPYC L3 = per-CCX 受害缓存，跨核预取进不了
   决策核缓存域；prefetchw 变体偷所有权更糟（+60-90 P90）。轮间没有任何用户态保温手段。
9. **分支税看单站点结果熵，不看分支数（8.10 融合战役四连probe定谳）**：同一避弹算法，
   分支形态 +40-50ns（172371/172441 布局位移排除骰子），constexpr 备选表+cmov 掩码形态 **-10ns**
   （172497，P99 1050→250 全塌缩）。管道漫步案再进一层：champv 59 分支读 150 / champi 105 分支读 290——
   差额全在步 1/2 探针：其位置由步 0 金值偏航反馈决定，位置分支被金值污染成真数据依赖（熵源）；
   交错 ILP 只退 10ns，串行链非主因。**多步贪吃唯一合法形态 = 扫一次 + LUT 表步（冠军/T-1 同构）。**
   附标定：champ* 极简底盘系数 ~0.32ns/指令（400→160 / 652→240 两点拟合，高于 §1 的 0.2——
   小 .text 无罚则区间的裸系数）。

## 3.5 金块寿命与收入物理（8.9 定律级测量）

- **金块寿命：中位 2 轮 / P90 6 / 最长 10**（静窗日志 46 死亡样本）。存量不可耕——
  一切"覆盖收割/罐头计划/蛇形巡耕"架构收入封顶 ~400（planA/B/C 三证）；
  收入唯一机制 = 逐轮反应式拦截。休耕/轮作收益与存量无关，勿按存量建模。
- **P90 是分位数（可武器化）**：500 轮中贵轮 ≤~45 个时 P90 落在便宜类。罐头轮实测
  P50 40-70 / P90 60-90（planbot）。打纯延迟指标的终极武器；但罐头盲轮撞金块寿命，
  收入与之互斥。波轮/开局轮（~33 个）天然可藏进分位数。
- **P90 尾部无相位结构**：尾轮均匀散布（%20 边界/扫掠窗富集皆无），P90≈P50+均匀抖动
  (30-120, 随窗口)。压 P90 的正道 = 压 P50（足迹）+ 等轻窗，无定点手术可做。
- **map2 solo 收成红利**：开放车道地形，硬锁冠军 vs 空壳 1910-2119（map1 同构 1802）。
- **刷金场（map1，13 局按可见轮归一化，8.9）**：每格每轮刷率 环1-2 峰 0.032-0.035，
  环3=0.025，环4=0.019，环5 腰斩 0.010，环6+ ≤0.004 死地；单次刷额环 0-6 平坦 ~6.0。
  环 7-12 首见金额 10-15/P90 21-25 = 无人收割的堆积（间歇远征的猎物）。
  **收入=命中率×咬合值，命中率是绑定约束**（对手进账轮 525-660/1000 单位轮 vs 我方旧 119-236；
  咬合值双方天然持平 ~4）。轨道/偏置场必须铺在刷率等高线上（v5h 热场刀 ×2.6 实证）。

## 4. 测量协议（验收纪律，违者必被窗噪骗）

- **窗口漂移 ±30ns、P50 读数 10ns 量化、单局收入噪声 ±300**——单局 A/B 对 <40ns/<300金 的效应量无判别力（一天内被骗三次的教训）。
- 等价重构：perf 指令数 + `tests/pair_diff.py` 逐位 0/500，**零局数**验收。
- 行为变更：≥3 对同窗交错批量取中位 + 行为体检（首拾取轮/冻结/撞位）。
- 里程碑加冕：6+6 批量。
- 延迟读数必配行为体检：冻结单位少跑内存会"假快"（冻结红利案）。

## 5. 工具链（开发机 `~/goldrush/`，与评测机同构 EPYC Zen4）

```bash
# 构建（本仓唯一构建命令; 换图需重烘焙 player.cpp 内 BAKED_W1/ORT_*）
g++ -std=c++17 -O3 -march=native -fPIC -Wall -Wextra -shared -o player.so src/player.cpp -Isrc

# 指令计数(perf 差分, ptrivial.so=空基线): (总数-2566352)/4481 ≈ 指令/调用
perf stat -e instructions ./bench logs/game_X.bin src/player.so

# 逐位对账 / 输入回放 / 本地周期
python3 tests/pair_diff.py a.so b.so logs/game_X.log
python3 tests/dump_inputs.py logs/game_X.log   # -> .bin 供 bench
./bench logs/game_X.bin a.so b.so              # 交错回放, 抗漂移

# 平台(每日 500 局配额)
./tools/arena.py submit --map 1 --vs <id> player.so:name
./tools/arena.py watch <gid> && ./tools/gamelog.py logs/game_<gid>.log
```
